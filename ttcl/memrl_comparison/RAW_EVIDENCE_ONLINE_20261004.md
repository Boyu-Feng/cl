# 不预定义动作语义的在线轨迹证据记忆：阶段结果（2026-10-04）

**结论：证据提取、保存和跨题调用均已打通，但尚无可重复的官方分数提升。**这轮没有训练或替换模型权重，没有人工定义 `clean/cool/heat` 等动作类型，也没有把环境反馈文本映射成手写技能规则。实验复用现有冻结 Qwen3-4B 推理服务与官方 ALFWorld／CLBench worker，不停止或改动其他 GPU 实验。

## 方法及失败定位

第一步让模型从完整公开轨迹写条件建议，并要求引用来源反馈原文。18 条来源轨迹中，13 条建议能找到所引反馈的字面子串，3 条引文不匹配，2 条 JSON 截断；字面引文**不等于**语义支持。模型仍会把 `Nothing happens.` 对应的动作写成建议，或把一次扑克输赢推断为动作最优性。该写法不安全，故没有进入正式测试。冻结诊断位于 ignored 的 `results/memrl_credit_training/20261004_grounded_writer_v2_pilot/`，设计 SHA256 为 `34b8c72167ea01c80785f4f1784cb9ef29cf763577adb7ae86085d45f00149ff`。

随后改为让模型**只选最多三条步骤号**；存储的经验卡包含该步的原始公开动作和环境反馈，不由模型撰写结论。来源任务、输入内容哈希、公开轨迹摘要和步骤号都保存。原生 MemRL 的 intent–experience–Q 记忆继续在线更新。v1 只给原生 MemRL 已选中的记忆附卡；ALFWorld 的来源成功记忆未进入下一题的原生候选，因此经验卡实际展示 **0 次**。v2 在原生检索旁增加基于任务文本嵌入的独立证据检索，最多附一张卡，受原有 2048-token 记忆预算约束。v3 去掉“来源整题奖励必须大于 0”这一跨领域不成立的筛选：负分或 0 分轨迹也能提供真实工具结果，但卡片明确标记为过去实例，数值须在当前题重新核对。

## 下一版的信用分配

不能把“来源整题成功”当作该卡有效，更不能把附卡链的所有终局奖励广播给每条卡。已实现通用的 `evidence_utility.PairedUtilityGate` 逻辑原型，**尚未接入上述执行链**：它只接受同一原生记忆状态、同一当前任务、仅一张卡开关不同的配对官方奖励；以输入内容和来源内容哈希绑定记录。至少两个**不同当前任务输入**显示正差且没有负差，才允许自动激活；同一题多种子重复只用于发现噪声，负差进入隔离。当前小样本没有卡达到这个条件。后续应从共同冻结记忆快照做单卡 on/off，而不是把两条已经分叉的在线链误认为单卡因果比较；再用独立任务检验长期在线收益。

目前不应以此版本做全量 ALFWorld／CLBench 的效果宣称。四个已有 CLBench 非 Docker 领域已做小规模机制检查；另外两个 Docker 领域仍受当前账户无法访问服务器 Docker socket 的基础设施限制。若继续做全量，应先在新训练／校准来源中获得可重复的跨题收益，再冻结方法和预算，按官方划分运行并报告所有失败。
