# CLBench 数据库：补齐字符串动作候选的反馈门控

## 要解决的问题

v22 的类型化证据能为数据库动作 `{"action":"QUERY","content":"..."}` 生成字符串复制候选，但旧门控只用频谱数组和 Cohort 数值的官方奖励差训练。因此数据库完整 30 题中 413 次决策全部弃权。这不是超网络不生成 LoRA：参数记忆仍按原流程读写，只是证据操作没有可用的字符串门控。

## v25 方法与数据界限

保留 v22 的轨迹来源、LoRA 控制臂、类型化证据提取和原数组/数值门控，新增独立的 `sql_feedback_schema_query_copy` 操作。它只在当前动作为 `QUERY`、查询包含此前公开反馈已证实不存在的表/列名时，才考虑从更早的自身轨迹复制一条执行成功的表名发现查询。候选保留来源题序、轨迹、动作和反馈哈希；当前 JSON schema 再次验证；同一题最多采用一次。没有直接复制历史最终答案。

新门控的训练目标是**当前查询反馈与来源查询反馈的等级差**（错误 −1、空结果 0、有内容结果 +1），不是 CLBench 最终奖励差。候选和标签绑定 v22 原始 LoRA 轨迹、官方目标实例、初始问题内容哈希、动作及反馈内容哈希。索引 0–12 用于训练、13–17 用于开发检查，18–29 不用于拟合。64 条已审标签中训练 36、开发 28；按题聚合后训练有 9 个目标、开发有 5 个目标。训练目标级平均反馈差为 +0.81481，正态近似下界 +0.48184；开发 5/5 个目标平均反馈差为正。因此门控启用。重复动作高度相关，该下界不是有严格覆盖率保证的置信区间。

这一步解决了**“该操作类型完全没有门控训练、只能弃权”**的覆盖缺口；它没有训练出能预测最终官方奖励收益的 SQL 门控。设计此操作前已经检查过旧 v22 的完整 30 题轨迹，所以索引 18–29 也不能称为完全盲测。

## 全量结果

同一官方 seed 42、完整 30 题，逐题重置，两臂共用按 LoRA 控制轨迹建立的历史来源；原冻结超网络与 LoRA 参数记忆流程不变。无 LoRA 独立基线来自先前完整运行。

| 方法 | 可评分题 | 官方均分 | 与无 LoRA 的逐题奖励差 |
| --- | ---: | ---: | ---: |
| 每题独立、无 LoRA、无证据 | 30/30 | 0.02222333 | — |
| LoRA 参数记忆 | 30/30 | 0.02222333 | 0/30 题改变 |
| LoRA＋v25 SQL 反馈证据 | 30/30 | 0.02222333 | 0/30 题改变 |

v25 在 30 题中实际采用 SQL 候选 **20 次**，另有 390 次 SQL 决策保持原动作；原 v22 的类型化门控有 410 次弃权。20 次采用分布在 20 道题，20 道题的执行轨迹均改变，10 道题的最终答案文本改变；20 条被采用查询的公开反馈均有结果。但所有已改变题的官方奖励仍与对照相同，0 次任务失败。LoRA 记忆写入 1 次、在 6 道题的最终记录中处于挂载状态，仍没有逐题奖励收益。完整运行审计通过，报告 SHA-256 为 `ad6867b56a461564a0ece0f299699776f6002c86b1da8e0fc2a69c91a58549f8`。

## 解释和限制

数据库评分在最终答案错误时给予 0；因此把一个查询改为有结果的查询，并不会自动带来整题收益。模型还需要从反馈中识别实际表关系、构造正确聚合查询并提交正确答案。本次直接改动作已经绕过了“模型是否服从经验提示”的环节，却仍没有涨分，说明瓶颈还在后续推理/答案质量。当前正反馈源查询主要来自同一条早期轨迹，来源多样性也很低。

本方法仍是通用证据接口下的**数据库操作适配器**，不能把 SQL 表名发现操作当成 ALFWorld、扑克或 Cohort 的共同操作。若保持原问题所要求的“用官方最终奖励差训练门控”，这次 20 个在线采用样本的最终奖励差全为 0，按收益不足应弃权；不能把反馈代理标签说成最终奖励监督。后续要验证跨域收益，需分别定义合法动作约束与经过官方配对回报审核的使用操作。

代码入口：`sql_feedback_evidence_v25.py`、`train_sql_feedback_gate_v25.py`、`clbench_sql_feedback_v25.py`、`audit_clbench_sql_feedback_v25.py`。原始标签、审核文件、门控模型、逐题轨迹及审计 JSON 按仓库规则保存在 ignored `data/annotations/` 与 `results/trajectory_hyperlora/`；v24 的部分运行被停止并保留，不计作完整成绩。
