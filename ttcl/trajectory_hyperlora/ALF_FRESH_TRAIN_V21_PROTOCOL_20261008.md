# 官方 ALFWorld 训练分区：本地未曝光路径的冻结确认题序

此前官方 `valid_unseen` 134 个本地游戏路径均已在旧报告中出现；`valid_seen` 尚未出现的游戏分布不覆盖“查看物体”家族。为了在新门控或生成器结果出现前保留**六家族均衡的本地路径盲测**，本协议从官方 `train` 分区冻结 90 个此前未出现在本地 JSON 记录的游戏，三条互不重叠的 30 题顺序，每条六类×五题。这是官方 ALFWorld **训练分区内的留出确认集**，不能称作官方 `valid_unseen` 测试，也不能与已曝光的 `valid_unseen` 成绩合并作单一泛化指标。

选择前用 `rg --no-ignore` 扫描 `results/`、`data/annotations/`、`ttcl/results/`、`ttcl/trajectory_hyperlora/` 和 `current_work/` 中的 JSON 游戏路径；必须显式包含 Git 忽略目录。扫描快照保存在 Git 忽略的标注目录，SHA-256 `5beca3e8f7ce1c282c5467bcc6f6e8fa22fceb0d4019fe21a35a39b2d8a94453`，当时共 2,118 个已出现的官方 `train` 游戏路径；未出现的有 1,435 个。排序只用固定盐和游戏路径 SHA-256，不读取题目奖励。每家族先取从未在扫描快照中出现的任务目录，再用已曝光目录下的新 trial 路径补足；每个入选游戏来自不同任务目录。

**不可消除的限制：**“查看物体”家族仍有 22 个未出现的游戏路径，但它们的任务目录全部已有其他 trial 在旧记录中出现。因此 90 题中该家族的 15 题只做到**游戏路径未曝光**，不是全新任务目录；其余五个家族的 75 题均来自本地未曝光目录。计划文件 [alf_fresh_train90_v21_plan.json](alf_fresh_train90_v21_plan.json)绑定每个官方游戏内容哈希、家族、顺序、目录曝光标记和冻结曝光快照哈希，计划 SHA-256 为 `856c9a33495dbccc032477795f121a13ad97cf35ccb7785234cfff4ec522d812`。`freeze_alf_fresh_train_v21.py check` 只对冻结快照复核计划，后续产生的新结果不会追溯改写选择过程。

这 90 题只在训练域超参数、v14/v18 开发比较和新方法冻结后用于一次确认；**不得用于选超参数、挑 checkpoint 或修改算法**。运行前仍须为每个方法重新生成经审核的目标与输入内容绑定，记录方法自身历史的因果哈希链，从空历史开始按三条顺序运行；成功使用官方环境 `won`，每回合沿用 50 步、合法命令、两轮历史和两次重复抑制预算，并逐动作独立原环境重放。至少比较持续写入、固定首条、无记忆、同源文本和原生 MemRL，按顺序及六家族分别报告。当前**只有题序冻结，尚无确认成绩**；它也不能替代真正未接触的外部任务或新官方测试集。
