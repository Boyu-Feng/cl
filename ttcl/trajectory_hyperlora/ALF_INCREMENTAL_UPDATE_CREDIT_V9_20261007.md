# 用未来任务反事实回报训练在线 LoRA 写入决策：v9 数据协议

此前官方 `valid_unseen` 36 题上持续运行均值 LoRA 为 19/36、固定首条为 20/36；新冻结 `valid_seen` 36 题经独立原环境审计则分别为 15/36、15/36。新轨迹写入会改变不少动作，但尚未带来净收益。仅把整段成功轨迹编码、无条件平均，训练信号没有回答“**这一次写入是否改善下一道题**”。v9 先在官方 `train` 任务上直接采集这个反事实量，不调整已保存的 v5/v6 模型与评测结果。

令旧成功轨迹编码为 $z_o$，之后取得的成功轨迹编码为 $z_n$，未来题为 $q$。同题同冻结演员的两臂分别使用 $m_0=z_o$ 与 $m_1=(z_o+z_n)/2$，通过相同超网络生成任务条件 LoRA，记录官方终局奖励差

$$D(z_o,z_n,q)=R(\pi_{B(m_1,q)};q)-R(\pi_{B(m_0,q)};q).$$

在 ALFWorld 的确定性单次尝试中，$D\in\{-1,0,1\}$。正值只说明在**当前冻结演员、任务与步数预算**下这次写入有利；负值说明当前配对不该无条件写入。$D=0$ 不能推断两个 LoRA 等价，因为完整动作轨迹可能改变却得到相同终局。不同来源顺序和不同未来题的样本不能当作完全独立的统计单位。这一对照仍不是完整的各方法自身策略闭环在线学习。

输入从已有内容审核的 8 条官方 `train` 自身成功来源中按时间先后固定六次转移：`(0,1), (1,2), (2,3), (3,7), (4,5), (5,6)`；每次与此前冻结的 18 道、来源游戏不重叠的官方训练目标题交叉，共 **108 对、216 条环境回合**。任务家族只用于事后描述，**不进入源向量、超网络或未来可学的门控输入**。两臂均使用同一 v5 冻结参数、同一初始环境、50 步、合法命令约束、64 token 动作、两轮对话和循环保护。单条新成功来源只在“写入”臂改变运行均值及据此生成的 LoRA；历史文本不直接进入演员提示。新内容绑定审核文件 SHA-256：`102ff9e8f664750216e3ec7162b22cadeb01c70f42715d4d07684d19ded0718a`，位于 Git 忽略目录。

数据收集器 `collect_alf_incremental_update_v9.py` 和独立重放器 `audit_alf_incremental_update_v9.py` 是新文件，保留旧版。单配对冒烟的两臂均为零回报，两条轨迹已在原环境逐命令重放一致；这只验证协议和实现，不计为方法收益。完整数据再以原环境逐命令重放、来源／目标内容哈希和来源向量稳定性审核。任何运行失败或无效动作均保留在原始报告，不当成奖励零静默跳过。

几何分析器 `analyze_alf_incremental_update_v9.py` 也先于完整标签写定。它要求已有审核通过，再用此前冻结的来源／目标题向量重算修正潜代码并核对运行时范数，按整次来源转移和整道未来题分别报告奖励差、动作轨迹差、代码变化及事后逐配对上限。该上限不可在线部署；共享来源或目标的配对不会被当作独立随机样本来报显著性。

为了不把潜代码误当成实际矩阵，`analyze_alf_incremental_effective_matrix_v11.py` 进一步在同一个冻结 Qwen 上重建两层适配器的 $B$，以冻结 $A$ 精确计算有效 $\Delta W=BA/r$。它核对来源向量哈希、修正代码范数和未来题上下文，再按写入有利／有害／同分报告矩阵相对变化和余弦。有效矩阵的 Frobenius 范数通过 $A^\top$ 的 QR 分解计算，不需要实例化整块 2560×9728 矩阵。它仍是描述性机制分析；相近的矩阵范数不能决定终局奖励的符号。

低容量门控探针 `probe_alf_incremental_gate_v10.py` 也在查看完整标签之前固定。它只读已经审核的 $D$ 和冻结 v5 PCA 坐标，使用无家族槽的常数、来源、目标题、来源×目标题四种特征，以及预设 ridge 正则强度；内层按组选择特征／强度，外层分别整次留出来源转移、整道留出目标题，只有预测 $D>0$ 才选择写入。它同时报告无条件冻结、无条件写入和不可部署的逐配对事后上限。两种交叉验证仍在同一批训练来源和目标题上，PCA 也来自旧训练库；它只能筛掉明显过拟合的门控，**不能替代另行冻结的在线官方评测**。

若审核后存在足够跨来源、跨目标题的非零 $D$，下一步学习不依赖手工家族槽的**写入／冻结**门控 $g_\psi(z_o,z_n,q)\in[0,1]$，令 $m'=z_o+\tfrac12 g_\psi(z_n-z_o)$。这样 $g=0$ 与 $g=1$ **恰好对应本轮实际评测过的两臂**；本轮没有评价完全替换为 $z_n$，不能用这些标签宣称学会了任意 $m'=(1-\alpha)z_o+\alpha z_n$ 的最优 $\alpha$。若要学习更广的写入幅度，应另收集额外 $\alpha$ 的配对回报或用环境奖励做在线策略梯度。训练目标应是未来任务的**更新相对冻结回报**，而非仅模仿成功轨迹或预测轨迹能否复述。二元奖励在许多配对上可能同为零或同为一，故模型训练与新题序验证必须按整道目标题、最好按计划序列隔离；不能用同一 18 题训练后再报告其拟合成绩为泛化。正式在线检验需从空历史出发，与无写入、无条件均值、首条冻结、最近成功、原生 MemRL 和同来源原始文本对照，并运行多个独立题序。当前文件规定实验输入与判定边界，尚无 v9 成绩。

为降低单条顺序的偶然性，已在读取 v9 完整训练结果前冻结[官方 `valid_unseen` 三题序计划](alf_valid_unseen_multiorder_v10_plan.json)：每序 30 题、六类各五题，三序的游戏目录互不重叠，计划 SHA-256 `17dcd09f00aeb244e5d3b8c59204ea3c9c87f188010c64cd378c17a62b867803`。需要如实注明：本地旧报告已命名 `valid_unseen` 全部 **134** 个游戏，因此这些是**预先冻结的新顺序**，不是从未看过的新游戏，也不足以单独构成论文最终盲测。以后实施仍须为三序另外生成内容绑定审核目标，并在新模型选择后冻结评测代码。
