# 首个动作与后续参数策略：四结果精确分解

[v12 固定策略动作干预](ALF_INCREMENTAL_FIRST_ACTION_V12_20261008.md)在 16 组写入／冻结终局不同的官方训练题配对里，各得到四种完整回合奖励：冻结 LoRA 选冻结动作、冻结 LoRA 选写入动作、写入 LoRA 选冻结动作、写入 LoRA 选写入动作。脚本逐组复核两臂在首个不同动作**之前的完整回复、命令和观察完全一致**，并绑定已独立重放的 32 条干预轨迹。

令该共同前缀为 $h$，冻结／写入策略为 $\pi_f,\pi_u$，原生动作分别为 $a_f,a_u$；$J_\pi(h,a)$ 是强制执行动作 $a$、随后继续固定策略 $\pi$ 的终局奖励。写入的配对效用有两种都**精确**成立的路径分解：

$$
\begin{aligned}
D&=J_{\pi_u}(h,a_u)-J_{\pi_f}(h,a_f)\\
 &=\underbrace{J_{\pi_f}(h,a_u)-J_{\pi_f}(h,a_f)}_{\text{冻结策略下换首步动作}}
 +\underbrace{J_{\pi_u}(h,a_u)-J_{\pi_f}(h,a_u)}_{\text{固定写入动作后换后续策略}}\\
 &=\underbrace{J_{\pi_u}(h,a_u)-J_{\pi_u}(h,a_f)}_{\text{写入策略下换首步动作}}
 +\underbrace{J_{\pi_u}(h,a_f)-J_{\pi_f}(h,a_f)}_{\text{固定冻结动作后换后续策略}}.
\end{aligned}
$$

两个动作效应的差 $I=[J_{\pi_u}(h,a_u)-J_{\pi_u}(h,a_f)]-[J_{\pi_f}(h,a_u)-J_{\pi_f}(h,a_f)]$ 衡量**动作与后续参数策略的交互**。因此“多少收益归动作、多少归参数”没有唯一无条件答案；必须说明所固定的后续策略或动作。

在这 16 个按胜负不同事后选出的配对中，**3 组**交换动作会在两种策略下都翻转终局，**4 组**两种策略下都不会翻转，另外 **9 组**只在一种策略下翻转，对应非零交互。求和后，总写入增益为 $+4$；沿冻结策略路径拆成动作 $+1$ 与后续策略 $+3$，沿写入策略路径拆成动作 $0$ 与后续策略 $+4$。这些求和仅描述选中的配对，包含重复目标题，不能当作总体平均因果效应或持续在线收益。

这给下一版训练目标一个约束：完整未来题的写入／冻结回报差 $D$ 仍是主标签；对首个动作给正负信用时，必须标明**在何种 LoRA 后续策略下**干预得到它。仅凭 LoRA 矩阵的范数、首个分歧或一条轨迹成功与否，都不能替代这个条件。后续多步状态造成的效应仍需独立实验，v16 只分解首个不同动作所在的局部节点。
