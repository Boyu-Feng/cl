# ALFWorld 第二批 30 题：轨迹 LoRA 与 MemRL 同来源对照

用户询问的“25 个对”是**奖励训练版超网络从正确同类成功轨迹生成 LoRA 后，在第二批普通放置训练域留出题上的单次官方通关数：25/30**。同批无 LoRA 为 14/30，错配同类成功轨迹 LoRA 为 26/30。三者都是同一冻结 Qwen3-4B 演员、同一 30 步与 64 token 动作预算、官方 `won` 指标；第二批 30 题在看过第一批结果后才追加，属于探索性确认，不是官方 `valid_unseen`。

## MemRL 同题实验

为回答同一批题上 MemRL 的表现，使用与正确历史 LoRA **逐题相同、已审核并在环境中重放成功**的 sibling 专家轨迹。每道目标题从空 MemRL 存储开始：把那一条来源的公开观察、动作和反馈交给仓库已有的上游 MemRL 本地适配写入器，用官方成功奖励 `1` 更新 Q，再用 BGE-M3 对当前目标题检索，所得经验放进**同一个冻结 Qwen**的系统提示。目标游戏依然只给当前公开观察和可用命令，保留最近两轮演员历史，限制可用动作并运行最多 30 步。MemRL 写入一次、检索一次；30/30 均成功写入且检索到文本，无运行失败。

| 同一批 30 道题 | 官方成功 |
|---|---:|
| 无 LoRA、无记忆 | 14/30 |
| MemRL，单条正确 sibling 成功历史 | **19/30** |
| 奖励训练超网络，正确 sibling 历史 LoRA | **25/30** |
| 奖励训练超网络，同类错配历史 LoRA | 26/30 |

逐题配对审计：四组使用同一批 30 个目标题；MemRL 与 LoRA 的目标内容绑定一致，**30/30 条无 LoRA 完整轨迹逐字段相同**。正确历史 LoRA 与 MemRL 同时获胜 18 题，只有 LoRA 获胜 7 题，只有 MemRL 获胜 1 题，两者都失败 4 题。MemRL 相对无记忆新增胜利 7 题、失去原胜 2 题，说明它在这批题上也有正向数值变化；正确历史 LoRA 总体再多赢 6 题。LoRA 对 MemRL 的逐题不一致项为 7 比 1，双侧精确符号检验 `p=0.0703125`；30 题不足以断言一般情况下稳定优于 MemRL。

这项 MemRL 对照是**每题单条相同来源、空库重新开始**，用来比较文本经验与参数经验的接口。它不包含跨题持续累积，也没有额外喂给 MemRL 训练域中的其他历史，因此不代表完整长期在线 MemRL。LoRA 超网络此前在训练域接受过奖励筛选训练，而 MemRL 写入器没有在这 30 题上训练；训练投入不相同。LoRA 错配来源 26/30 略高于正确来源 25/30，仍不能把 LoRA 的收益归因于历史的具体任务信息；结果更支持普通放置类别内策略改变。不能把这组训练域留出结果与前述官方 `valid_unseen` 六题的失败后重试结果混算。
