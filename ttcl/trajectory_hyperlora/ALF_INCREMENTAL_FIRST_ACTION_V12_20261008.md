# LoRA 经验写入后的首个动作分歧：固定策略干预

本实验接续 [108 组写入／冻结配对](ALF_INCREMENTAL_UPDATE_RESULTS_V9_20261007.md)，检验动作轨迹不同能否直接定位信用。来源、目标均为官方 ALFWorld `train`；这 **16 组是从 108 组里按终局胜负不一致事后选出**，不是独立测试集，也不能用其中比例推断所有任务。原配对为新增成功轨迹后 10 组受益、6 组受害。

对每组找到两臂首个**不同命令**。先在同一冻结 Qwen、同一 LoRA、同一环境重置及 50 步／两轮历史／循环限制协议下完整复现各臂原回合；再各自保留原臂此前的命令、回复和参数，只在该步执行另一臂的命令，随后由**本臂原策略**自行继续。首个分歧前环境观察相同，替换命令在分歧状态可执行。标注逐项绑定来源轨迹、目标题、检查点、残差模型、原报告及两条完整轨迹的内容哈希。32 条新轨迹均经独立原环境重放，执行失败为零。

| 观测量 | 结果 |
|---|---:|
| 两臂原终局胜负不同的配对 | 16 |
| 仅交换首个不同动作后，冻结臂终局翻转 | 9/16 |
| 仅交换首个不同动作后，写入臂终局翻转 | 6/16 |
| 两臂终局都翻转 | 3/16 |
| 仅一臂终局翻转 | 9/16 |
| 两臂终局都不变 | 4/16 |

这些是**给定本臂后续策略的局部动作干预效应**。例如配对 10、49、54 在两臂交换首个不同动作后均翻转，说明该动作在这些具体回合和后续策略中有终局作用。配对 11、24、97、103 则两臂均不变：仅凭首个动作无法解释原有的写入／冻结胜负差。配对 26 和 98 是同一官方番茄题在两次来源转移下的重复目标：把写入臂的 `heat tomato 4 with microwave 1` 交给原本成功的冻结臂，会使冻结臂失败；把冻结臂的动作交给原本失败的写入臂，却仍未救回终局。重复目标不算独立样本。

因此下一版不能把“首个不同动作”一律当作正负经验标签。训练写入算子的主标签仍应是在相同未来训练题中完整执行“写入／冻结”得到的终局差；首个动作干预仅能在确有局部回报作用、且结合当时目标与观察时作辅助信用。对两臂都不变的例子，需要分析后续多步动作与观察反馈的交互；对只翻转一臂的例子，需要建模**动作与当前 LoRA 策略的相互作用**。这也是单用矩阵范数或一次动作分歧无法判断经验效用的原因。本实验不证明持续更新的整体收益，也不提供新超网络的测试成绩。
