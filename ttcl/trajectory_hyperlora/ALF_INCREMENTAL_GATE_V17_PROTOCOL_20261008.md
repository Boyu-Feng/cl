# 从未来回报学习是否写入新的参数经验：预先固定的门控实验

v14 在官方 ALFWorld `train` 中采集同一未来题上的两种真实回报：$R_u$ 使用新增自身成功轨迹后生成的 LoRA，$R_f$ 保留旧参数经验。训练标签为 $D=R_u-R_f$。v17 **不修改既有超网络或 LoRA 因子**，只学一个是否执行这次写入的二元决策；这样可先检验已观察到的负迁移是否能被任务条件信息预测。若有效，再研究联合学习新参数方向和写入幅度。

**适用范围限制：**v14 的每一臂都从**一条**旧成功轨迹出发，比较保留它与加入第二条轨迹后的等权均值；六种来源转移也都是这种 1→2 条写入。因此 v17 的标签只支持“是否接纳第二条成功轨迹”这一局部决策。第三条及之后的持续均值写入改变了旧记忆状态和新轨迹权重，不能把 v17 在两条来源上的成绩外推为持续学习效果；后续必须单独采集完整前缀的 2→3、3→4、4→5 等写入／冻结配对，并检验方法自身闭环。

输入来自同一个冻结 Qwen 编码器：旧自身轨迹的全局与逐动作反馈差分、新轨迹加入均值后的相应向量，以及未来题的初始目标和观察。来源描述符把旧表示与这次变化并列，当前题表示来自同一演员的目标编码；**任务家族名、动作类别及人工技能槽不输入门控**。来源向量按六次训练来源的均值中心化，目标题向量只按 **60 道训练题**的均值中心化，再单位归一化；旧 18 题的原始目标余弦平均约 0.988，中心化用于防止共同方向淹没题间差异。核函数在来源和目标题余弦上分别使用指数相似度，再比较来源核、目标题核、两者乘积及平均四种组合。温度仅在 $\{0.25,1\}$，岭正则仅在 $\{0.1,1,10,100\}$ 中选；恒写与恒不写是显式候选。训练时以配对的完整环境奖励差拟合核岭回归，预测 $\hat D>0$ 才写入。

只用 60 道训练题上的 360 个配对选择超参数：一轴把每家族的 10 题按预定位置划为五折，整道题留出；另一轴把六次自身轨迹来源转移逐组留出。选择两轴交叉验证收益之和最大的候选，平手优先原有的**恒写入**规则。这里家族只用于让验证折平衡，不输入模型。选定后重新拟合全部训练配对，**一次**评估 18 道目录隔离开发题的 108 个配对，并同时报告恒写、恒不写。开发题不参与候选追加或调参。后续仍须在官方 `valid_seen`／`valid_unseen` 自身闭环多顺序中检验，对照固定首条 LoRA 与公平文本记忆；v17 的开发成绩不能替代正式确认。

特征提取与训练代码已在读取完整 v14 新回报前固定：`encode_alf_incremental_pool_v17.py`、`train_alf_incremental_kernel_gate_v17.py`。两者必须校验三份完整的原环境审计报告以及内容绑定的冻结题单；特征、模型和逐题输出保存在 Git 忽略路径。此文件仅记录算法和预定评估，不报告未完成的成绩。

部署接口 `predict_alf_incremental_kernel_gate_v17.py` 复用训练时完全相同的来源／目标题归一化、核函数和岭回归权重；离线合成一致性检查使新题预测与训练核矩阵中对应列相符。接口要求 `old_count=1`，对 2→3 及之后的前缀直接报错，直至另用 v18 的完整前缀数据训练并验证新版本。常数恒写／恒不写候选也遵守这个适用范围，避免把 v17 的局部决策误标为通用持续记忆策略。
