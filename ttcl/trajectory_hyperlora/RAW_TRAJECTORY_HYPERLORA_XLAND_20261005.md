# 原始轨迹到 LoRA：XLand 受控验证（2026-10-05）

## 问题与方法

此前的 XLand 读取器用人工编写的“目标物体在动作后是否出现”特征，最多证明数据有信息，不能证明超网络自己学会抽取经验。本实验改成：把历史的公开观察、口袋状态、动作、奖励、结束标志和任务目标交给通用编码器；Transformer 把整段历史编码为 `z`，超网络输出一个秩 8 的 LoRA `B` 因子。目标策略只收到当前观察与目标，历史仅通过生成的 LoRA 影响动作：

`z = E_phi(trajectory), B = H_phi(z), logits = f_theta(query; W + 2 B A / 8)`。

策略主干和动作输出层**随机初始化后冻结**；输入值编码器、轨迹编码器、超网络及共享 LoRA `A` 因子参与训练。模型输入**没有**规则类型、规则 ID、物体匹配标签、目标动作或人工检查的 tile-delta。前后观察由同一通用网络编码，差值只是通用的转移表示。当前策略是一个小型冻结神经网络，**不是 Qwen、ALFWorld 智能体或 CLBench 模型**。

主要损失是后续目标动作的交叉熵。配对版本另加 `softplus(margin - (logit(正确动作)-logit(相反动作)))`：同一个公开目标问题配上相反的历史时，动作标签恰好相反。这一项只用未来动作标签，不告诉模型是哪种规则。当前没有 RL 或在线更新。

[LatentSkill 原论文](https://arxiv.org/abs/2606.06087) 和 [官方代码](https://github.com/yuaofan0-oss/LatentSkill) 提供了“编码器/超网络生成 LoRA、冻结主干、用后续行为监督”的参考。LatentSkill 的输入是**文本技能文档**，先做文档重建/补全预训练，再做轨迹监督；这里直接把原始历史轨迹作为输入，因此不是对该论文的复现。

## 数据与审计

公开 `xminigrid==0.9.3` 的 `small-1m` 规则资产在本机为 SHA-256 `c9c8ec0ec06d6337481e07c13872cd89df201e787093fc718e7ec368910195bf`。按**生产规则数组**而不是任务配置去重，固定 seed `202610051` 选择训练/开发/测试规则 512/128/128；冻结划分文件 SHA-256 `b05c81455a05c309812f106a0716fa23ae8b12a17d44406d91e37aabfe1ffdf5`。划分与先前的小样本实验不同，不能直接拼接分数。

使用真实 XLand 转移先收集单对象候选 184/51/34 条，失败 0；再构造两对象、相反隐藏规则的交叉历史 92/25/17 组，失败 0。每组有两份相反历史，每份历史问两个目标，因此监督/评估问题数为 **368/100/68**。两份历史的来源动作序列、全局动作次数、全局奖励总和，以及对应目标的公开初始状态相同；同一份历史的两个目标也要求相反动作。这限制了“多数动作”和“只看总奖励”的捷径，但设置仍是人工构造的两类规则任务。

候选经独立脚本复核动作序列、来源和目标状态变化、环境奖励、规则划分及逐问题的规范输入哈希。审核标注文件在 ignored 路径 `data/annotations/xland_crossed_reviewed_large_20261005.json`，SHA-256 `a52888826a0c79f0bdb807d31df33c8a02207dd77585c6ba92add64111b43902`。候选文件、标注、逐题结果及权重均不提交 Git。

## 结果

开发集选择检查点；测试规则从未用于训练或选检查点。两个种子训练 2000 步、学习率 `0.001`，成对损失权重 `1`、margin `1`；成对版本分别选中第 1400、2000 步。`错历史` 是同一公开问题配另一份相反的历史，`空历史` 是真正不挂 LoRA 的冻结策略。下表为正确题数：

| 训练 | 种子 | 开发集：正确历史 | 测试：正确历史 | 测试：错历史 | 测试：空历史 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 交叉熵 + 配对损失 | 42 | 77/100 | **52/68** | 16/68 | 34/68 |
| 交叉熵 + 配对损失 | 43 | 91/100 | **54/68** | 14/68 | 34/68 |
| 仅交叉熵 | 42 | 51/100 | 34/68 | 34/68 | 34/68 |
| 仅交叉熵 | 43 | 51/100 | 34/68 | 34/68 | 34/68 |

配对版本的训练集均为 368/368，测试集的历史互换分别令 52/68、56/68 个问题改变预测。在同一份历史的两个目标之间，预测出不同动作的历史分别为 22/34、30/34。**这支持在当前受控设置中学到了来源依赖的动作映射**；仅交叉熵在相同预算下仍停留于机会水平，说明优化信号的设计很关键。小划分（14/3/5 组成对历史）上，即使某个种子把训练集拟合到 56/56，测试也只有 10/20；扩大训练来源后才出现上述留出提升。

一个测试例把生成的 `[1, 6, 8]` LoRA `B` 因子保存并重新加载。策略仅使用目标状态、目标和该因子即可复现原预测，最大 logit 差约 `1.9e-6`：无 LoRA 选动作 `3`，挂对应 LoRA 选正确动作 `0`。因而起作用的是可缓存的参数更新，而非把历史文本再次放入策略输入。导出的因子和完整检查点仍只在 ignored `results/` 中。

## 边界与下一步

这是一个**小型冻结策略模型上的受控 XLand 实验**。数据只覆盖两类由环境实现的隐藏规则、固定的来源/目标布局和一步目标动作；还不能推出对任意轨迹、完整 XLand 任务、ALFWorld 或 CLBench 有效。模型还会出现种子差异和未泛化的目标，且没有实现 LatentSkill 的大规模预训练或 RL。

下一步先将同一输入/输出接口接到冻结 Qwen 的真实 LoRA 层，再测试更多规则机制、布局及多步后续回报；保留正确/相反/空历史三路评估，并和显式文本经验及在线 RL 比较。训练数据必须继续从新轨迹生成、独立复核目标与内容绑定，不能沿用旧历史 ID 的标签。

复现代码依次为 `prepare_xland_ruleset_split.py`、`collect_xland_rule_pairs.py`、`collect_xland_crossed_rules.py`、`review_xland_crossed_rules.py`、`train_xland_raw_hyperlora.py`。资产和环境安装路径见 [数据集试点记录](TRAJECTORY_DATASET_NEXT_STEP_20261005.md)；生成结果必须写入新路径，不覆盖已冻结运行。
