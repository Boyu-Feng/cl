# ALFWorld：完整训练经历的 LoRA 对照与在线轨迹学习方向（v51）

## 已完成的公平对照

旧超网络的检查点先在官方 `train` 的 31 道不同目标题、60 个审核动作目标上热启动 240 步；再对另 120 题的 698 个审核动作目标依次训练 1800、800、1000 步；最后对 33 题的 269 个审核动作目标训练 600 步。四段来源检查点哈希全部核对通过。旧方法的 68/134 来自这条累计 **4440 次更新**的谱系。

新建的静态完整 `A+B` LoRA 使用同一 Qwen3-4B 底座、相同的 rank 4、最后两层 `mlp.down_proj`、相同的审核动作目标集合和阶段顺序、相同阶段更新数；从随机初始化训练，不读取 `valid_unseen` 轨迹或奖励。它不能在推理时读取来源轨迹。直接 LoRA 使用适合自身的预先固定学习率，约 9.8 万可训练因子参数；旧超网络约 371.8 万可训练参数。故此对照匹配了训练目标、更新次数、有效 LoRA 矩阵和推理预算，但不声称严格匹配训练 FLOPs、参数数或初始 `A` 的逐元素取值；两种方法的辅助损失也不同。

在同一批已反复曝光的官方 `valid_unseen` 134 题中，每题一次、最多 50 步、每动作最多 64 token、两轮历史、合法动作筛选与重复动作限制相同：

| 方法 | 成功题数 |
|---|---:|
| 旧动态超网络，全训练经历 | 68/134 |
| 新静态完整 `A+B` LoRA，同目标与 4440 更新 | **77/134** |

逐题配对为旧超网络独有成功 **10** 题、静态 LoRA 独有成功 **19** 题，净差静态 LoRA +9，精确双侧 `p≈0.136`。静态 LoRA 的这 9 题优势不足以证明稳定胜出；但旧超网络在这次更接近训练预算的对照中没有优势。此前 68 对 52 的比较使用了只见到现场前缀 366 个动作目标、训练 600 步的完整 LoRA，因此不能作为超网络优于充分训练 LoRA 的依据。相同 134 题上，该较短训练的 LoRA 为 52，新对照为 77；两者同时改变了训练数据和步数，不单独归因于其中任何一项。

静态 LoRA 的 134 个正式环境回合已全部重放审计通过；旧超网络的回合来自此前已通过审计的冻结报告。新结果、来源分片、合并审计与训练报告分别为 `results/trajectory_hyperlora/alfworld_full_lineage_static_v51_unseen134_merged_20261010.json`、`alfworld_full_lineage_static_v51_unseen134_merged_audit_20261010.json`、`alfworld_full_lineage_static_v51_20261010.json`。评测分片预先固定为 `[0,70)`、`[70,102)`、`[102,134)`；第一进程在前 70 题后多跑出的两个回合没有进入合并分数，合并报告记录每份来源文件哈希与取用区间。

此前更严格的从零启动、同 366 个自身成功动作目标、同 600 步比较也显示：训练流后缀超网络 42/120、完整 LoRA 39/120（配对 `p≈0.648`）；已曝光 unseen 上超网络 46/134、完整 LoRA 52/134（配对 `p≈0.327`）。两批数据都没有证明超网络具有显著且稳定的直接 LoRA 优势。

## 下一步：真正按轨迹到来顺序学习

新实验应从随机超网络和冻结 Qwen 开始，按新的官方 `train` 任务流顺序运行。前期无 LoRA 演员只累积 **8 条自身环境确认的成功轨迹**；在第八条成功之后，仅用不同题之间的成功来源→目标题动作配对，训练一次短启动模型。目标题自己的完整轨迹不得作为该题的来源。来源不足的任务族继续使用无 LoRA 演员，后续成功再加入经验池。

此后每题先用当前参数作正式第一次尝试并记录奖励；任务结束后才重放核验本题轨迹、写入新的内容哈希绑定与审核目标。成功轨迹触发小步在线更新；失败轨迹先作为负来源保留，只有与可核实的成功行动或环境增益配成对后才进入修正损失。这样本题信息只影响下一题，不能倒流到自己的首试。训练器和评测器均保存每题更新前后参数摘要、来源索引、环境奖励与失败记录。

至少设置三组同顺序控制：在线更新超网络；只增长相同轨迹池、参数冻结的超网络；接收相同成功动作目标与相同在线更新次数的静态 LoRA。前两组用同一条既往来源，以隔离参数学习和简单检索扩容；第三组检验是否只要在线 LoRA 微调就有同样收益。以整条任务流的逐题单次尝试成功率和后续题配对改善为主要指标，再用不同但同族的来源置换检查具体轨迹内容是否必要。训练流机制实验不能冒充未曝光盲测。
