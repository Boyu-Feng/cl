# 用动作敏感方向探索轨迹 LoRA：真实 ALFWorld 回报先导试验

此前各向同性反向扰动训练的 72 对真实 ALFWorld 回合里，57 对正负扰动终局奖励相同，给出零奖励梯度；详见[奖励信号复核](ALF_REWARD_SIGNAL_AND_DIRECTION_20261007.md)。这轮只检验：在相同参数代码扰动大小与环境预算下，把扰动方向对准冻结演员当前动作间隔梯度，能否更经常得到**可区分的终局反馈**。这是探索分布的机制试验，**没有更新超网络权重**。

输入为旧版已审核的 8 条自身成功历史 × 18 道官方 ALFWorld `train` 游戏矩阵。从旧奖励训练的冻结配对顺序中，只依据同一目标游戏在八条来源下是否出现至少两个不同、可执行的**首步命令**，依次选前 24 个来源—目标题配对；本轮正负扰动的奖励没有参与选题。旧顺序曾按旧 LoRA 回报平衡抽样，因此这 24 对是**训练域、经筛选的子集**，覆盖十道不同游戏，不能代表 ALFWorld 总体。新审核标注重新绑定来源轨迹、游戏内容、旧矩阵回合、两个命令、演员检查点、扰动尺度、预算和输入哈希；24/24 个初始状态由原环境重新打开，两个命令均被确认为可执行。没有写死任务类别、技能槽或动作名称。

记旧 LoRA 的八维可加代码为 $c=0$，冻结演员在首个状态下对两条历史观察到的命令计算对数概率间隔 $m(c)$，取

$$u=\nabla_c m(0)/\|\nabla_c m(0)\|.$$

每对使用半径 $\rho=0.5\sqrt8$ 的四个参数代码：随机方向 $\pm\rho\epsilon/\|\epsilon\|$，以及动作敏感方向 $\pm\rho u$。随机噪声由审核序号与冻结种子确定，四臂共享同一来源历史、目标游戏、冻结 Qwen3-4B、原超网络、50 步／每步 64 token／两轮历史／两次重复抑制预算。每步仍由原超网络根据当前状态重新生成 LoRA，再叠加当回合固定的代码修正；正负分支只改变代码符号。两方向的**代码范数严格相同**，并使用同一个旧 LoRA 潜空间基。这里的随机方向经过单位化，动作敏感方向固定；这轮不是各向异性高斯策略梯度训练，其奖励差不能直接当作新超网络的无偏梯度。

24 对、96 个回合全部完成且零运行失败。新独立审核脚本在原 ALFWorld 环境逐步重放 **96/96** 条轨迹，核对可执行命令、每步反馈、官方终局奖励、输入内容绑定、随机控制和等范数参数几何，零审核失败。

| 训练域机制指标 | 等范数随机方向 | 等范数动作敏感方向 |
|---|---:|---:|
| 正负两臂首步命令不同 | 13/24 | **24/24** |
| 正负两臂终局奖励不同 | 5/24 | **9/24** |
| 48 个回合的成功总数 | **25/48** | **25/48** |
| 十道不同游戏中至少一对有奖励差 | 5/10 | 6/10 |

逐配对看，**5 对**两种方向都产生奖励差，**4 对**只有动作敏感方向产生，**0 对**只有随机方向产生，**15 对**两种方向都没有。四个动作敏感方向独有配对分布在三道游戏；按不同游戏合并，仅新增一道有奖励差的游戏。因此可报告“这批训练配对里，动作敏感参数探索产生更多非零回报比较”，不能报告稳定泛化收益或超网络性能改善。首步动作变化从 13→24 是方向构造的预期结果，也不能替代任务通关。四臂总成功数相同，表明这轮没有直接提升冻结策略的总体成功率。样本只覆盖十道训练游戏、来源配对不独立，且方法依据前期诊断提出；不把配对计数差写成投稿级显著优势。

这给下一版**实际训练**一个更有针对性的方案：使用冻结演员的动作敏感单位向量 $u(h,q)$，预先固定协方差 $\Sigma=\sigma_\perp^2I+(\sigma_\parallel^2-\sigma_\perp^2)uu^\top$，在相同总方差与回合预算下抽取 $\delta\sim\mathcal N(0,\Sigma)$，令 $c_\pm=\mu_\phi(h,q)\pm\delta$。反向完整回合奖励的均值梯度需使用 $\frac12(R_+-R_-)\Sigma^{-1}\delta$；不能把本轮固定方向的奖励差直接代入旧各向同性更新式。训练仍只用自身轨迹、当前公开观察和真实环境反馈，不输入人工类别。应预先固定动作对的获取方式，保留各向同性等回合对照，并在**游戏／计划序列隔离**的开发题及新的在线官方题序上检验冻结超网络、来源置换、固定首条、无记忆和同源文本经验。这个后续模型尚未训练或验证。

复现顺序：按 `EXPERIMENTS.md` 第 4 节恢复公开资产、旧 8×18 矩阵、v4 奖励模型和审核文件，在仓库根目录激活 Python 3.12 主线环境后运行：

