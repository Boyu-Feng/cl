# 从交互成功轨迹生成参数经验：自身轨迹后见蒸馏试验

这轮保留旧超网络和反馈奖励 v2/v3/v4 文件，所有新方法另建文件。目标是让冻结的 Qwen3-4B 演员在下一题**不再看到历史文本**，只挂载由已完成轨迹生成的 LoRA；训练生成器的目标应直接奖励下一题的正确动作或完整环境成功。当前研究仍是探索阶段，尚未证明论文级泛化或优于文本经验。

## 奖励梯度与矩阵诊断

反馈奖励 v4 将每个已审核的来源—目标题，用共享高斯扰动的 $c_+=\mu+\sigma\epsilon$、$c_-=\mu-\sigma\epsilon$ 各跑一个真实 ALFWorld 回合，以 $(R_+-R_-)\epsilon/(2\sigma)$ 更新轨迹到 LoRA 代码的网络。72 个不同配对消耗 **144 个环境回合**。审核后正／负扰动分别成功 **38/72、39/72**，相同配对旧 LoRA 为 **36/72**；在冻结官方 `valid_seen` 六类各两题上，v4、旧 LoRA、无 LoRA 均 **5/12**，同来源原始文本 **6/12**。没有测试收益，不能把 144 回合的训练与之前 72 回合版本作等预算优势比较。零训练／评测回合故障，逐题环境记录与输入哈希审核通过。

v3 的源条件化设计确实消除了第二版的饱和坍缩；但这与收益是两件事。复核有效矩阵时修正了 QR 因子转置：若 $A^\top=QR$，那么 $BA=BR^\top Q^\top$，有效 Frobenius 范数应按 $\|BR^\top\|_F$ 计算。重算均值为 **0.0652**，两层 **0.0544／0.0356**，不是旧脚本的约 0.062；来源余弦约 −0.123、中心化均值约 $4.1\times10^{-8}$ 的定性结论未变。来源相关的矩阵存在，但几乎没改善任务，这把主要瓶颈从“能否编码差异”移到“差异是否落在对下一题有用的策略方向”。

数学上，冻结演员在状态 $q$ 的候选动作 logit 变化近似为

$$
\Delta m_{a,b}(q,\tau)\simeq
[J_a(q)-J_b(q)]\,\operatorname{vec}\!\left(\frac{\delta B(\tau,q)A}{r}\right).
$$

$\|\delta B A/r\|_F$、有效秩和来源余弦都不包含 $J_a-J_b$，所以即使矩阵非零且随轨迹变化，也可能只改变无关 token、无效动作或失败路径。完整回合奖励及关键动作的有符号 margin 才能判断经验是否有用。长期更新时还要控制 $\|\sum_t\delta W_t\|$ 和不同经验的干扰；仅检查各因子范数不足以诊断策略漂移。

## 经环境重放的自身成功资料

已把官方 `train` 域现有 240 题三臂实验中的 **57 条基模自己成功轨迹**重新在原 PDDL 环境执行，633 个动作及反馈全部复现；输入绑定游戏文件、完整回合、观察、可用命令、动作、反馈和终局奖励。另筛出 **42 条旧 LoRA 分支自己成功而同题基模失败**的轨迹，321 个动作全部重放成功。后者不是“无辅助基模从零发现”的成功：收集时旧 LoRA 分支使用来自同类专家 sibling 的历史作为来源。两组都来自旧检查点祖先曾用的官方训练游戏，只能用于生成器训练和内部诊断，不能当独立测试。

对 42 条轨迹各取首／中／末动作，和 57 条基模成功历史中同类、不同游戏的两个来源配对，得到 **234 个**新内容哈希绑定的未来动作目标；六类目标分别是 54／60／3／15／60／42 个配对。生成器**没有类别输入槽**；按类别选训练配对只为保持来源与后续题大致相关。资料和配对有独立审计，原始 JSON/特征/权重放在 Git 忽略的目录，仓库保存代码与结果摘要。

## 后见软目标为何尚未解决信用分配

最初用 57 条基模成功轨迹作为未来动作目标，64 步成功动作交叉熵加冻结原始文本教师 KL 后，受祖先训练污染的 42 个开发配对上，平均动作 token CE：无 LoRA **0.677**、旧 LoRA **1.563**、原始文本 **1.444**、新 LoRA **1.583**。这批目标由基模已成功的游戏筛出，基模占优有明显选择偏差；它也曾将来源特征编码为 2048 token，却把旧 LoRA 和文本限制在 1024 token，不能作为公平性能结论。实验与失败记录保留，不把这 42 对当独立验证。

第二个候选把目标改成“旧 LoRA 成功、基模失败”的 42 条自身轨迹，来源特征、旧 LoRA、原始文本统一使用 2048-token 历史上限。冻结的旧超网络与演员不训练；新中心化双线性残差网络用 64 个内容绑定的不同游戏配对，最小化成功动作 token CE、原始轨迹教师的全词表 KL 与代码范数惩罚。64 步训练审计通过，平均 CE **0.203**、KL **0.489**；但 **27/64** 个动作 CE 小于 0.01、**39/64** 小于 0.1，说明许多教师强制状态下原学生本来就能输出成功动作，动作标签几乎不给“如何走出失败”的梯度。新版在冻结官方 `valid_seen` 12 题上 **6/12**，同来源旧 LoRA 和无 LoRA **5/12**，原始文本 **6/12**；相对旧 LoRA 净增 1 题、无丢失，内容及完整环境回合审计通过。这是**单种子、12 题、已多次用于研究的题单**，只算正向探索信号，不算稳定泛化，更不能说参数优于文本。

对 57 条已审核来源 × 126 个自身成功动作状态重算**有效矩阵**，新版 192 参数生成器的平均代码范数 **0.209**、平均 $\|\delta W\|_F$ **0.300**，两层分别 **0.254／0.159**，有效秩最多 4。固定状态下的来源相对离散度约 **0.988**、来源间平均余弦 **0.0065**；不同轨迹确实生成不同修正，且修正幅度比 v3 的 0.065 大，但这些都是训练域几何诊断，不足以把那一题成功归因于特定轨迹反馈。要做因果检验，还需要同目标置换历史、只保留成功／失败反馈等消融。

`valid_seen` 唯一新增成功是一道 `pick_heat_then_place_in_recep` 题：旧 LoRA 50 步失败，新版 31 步完成；两条命令轨迹首次在第 6 步分开，旧版去 `stoveburner 4`，新版去 `stoveburner 1`，两臂均无无效命令。这说明参数修正影响了可执行动作选择，但后续路径也不同，不能把成功归因于该单步选择或宣称它学会了特定炉灶规则。

检查 42 道训练游戏的失败基模轨迹与成功旧 LoRA 轨迹：每题都有第一处动作分歧，其中 **34/42 在第 0 步**；在分歧前共享的环境状态，基模动作与成功分支动作都在经回放核验的可执行命令集中。这提供了新的、需要独立内容审核的训练目标：在相同前缀比较两个动作，而不是对成功轨迹的所有后续动作平均给正标签。两条完整轨迹的最终成功差**不能自动证明第一处分歧的因果效果**，因为后续策略也不同。要降低混杂，应从同一共享状态分别执行候选动作，再用固定的同一个后续策略继续，或至少把它标记为弱偏好标签，不写成已验证的动作级奖励。

可据此定义生成器的下一版目标：在可验证的共同前缀 $q$，对成功动作 $a^+$ 和失败分支动作 $a^-$ 优化

$$
L_{\rm pref}= -w(q)\log\sigma\bigl(\beta[m_\phi(q,a^+,a^-)-m_{\rm old}(q,a^+,a^-)]\bigr),
$$

其中 $m=\log\pi(a^+\mid q)-\log\pi(a^-\mid q)$，$w(q)$ 只能由训练域的共同前缀、环境反馈或额外配对执行估计；若无配对执行，必须把 $w$ 降为保守弱标签。再约束 $D_{\rm KL}(\pi_\phi\|\pi_{\rm old})$ 和 LoRA 有效矩阵范数，在真正改变决策的状态上学习**有符号的**策略修正。终局奖励版本仍需与动作偏好版本独立比较，不能假定弱偏好总是正确。

## 投稿所需的下一道证据门槛

现有有效信号只有旧在线成功门控在研究已接触的 `valid_unseen` 36 题 **19/36 对无 LoRA 11/36**，以及本轮软蒸馏候选在反复接触的 `valid_seen` 12 题 **6/12 对 5/12**。为检验后者，训练和模型冻结后，新建内容哈希绑定的官方 `valid_unseen` 六类各两题题单，仍使用预先固定的来源 3、尺度 1、单次 50 步和相同演员。完整四臂及回合审计结果：**无 LoRA 3/12、旧 LoRA 5/12、同源原始文本 3/12、新生成 LoRA 5/12**；新旧 LoRA 逐题零新增／零退化。新版在 7 题改变了完整命令轨迹，这 7 题两臂都失败；其中五题首次分歧分别发生在第 15、32、33、43、47 步，另两题在第 4、49 步。它再次表明矩阵影响行为，但没有把变化对准决定胜负的时点。此官方 split 对**本轮生成器训练**未使用，项目历史则已有其他 `valid_unseen` 分析，不能宣称整个研究从未接触。

因此 12 题开发信号**未在新的 12 题确认中复现**。本轮没有证据支持“新软蒸馏超网络全面优于旧版”或“参数经验优于文本”；也尚未证明随题序持续更新胜过只保留一条历史。下一步优先实现第一处分歧的配对动作价值与可控 LoRA 信任域，再冻结另一张未用于挑选该算法的题单；不能在同一小题单上反复选择尺度后仍称盲测。

与已有方法的区别还需要严格界定：[LatentSkill](https://arxiv.org/abs/2606.06087) 已把文本技能编译为 LoRA，[CLAW](https://arxiv.org/abs/2609.12278) 已让超网络利用交互转移更新世界模型 LoRA，[ASCENT](https://arxiv.org/abs/2610.05303) 已从验证过的自身轨迹做测试时 LoRA 后见蒸馏。这里可检验的创新只可能是：**将交互轨迹中的奖励／反馈摊销成演员 LoRA 的一次前向生成，并在跨题持续使用中做到稳定收益**；这目前是研究目标，尚非已证贡献。

## 下一版矩阵生成假设：用动作敏感子空间替代旧潜变量 PCA

当前 v3/v4 和自身轨迹软蒸馏 v2 的残差都经由**旧超网络潜变量的 PCA 子空间** $U$ 注入：$\delta B=H_B U c_\phi(\tau,q)$。这个子空间只表示旧生成器在训练配对上的主要变化，未必包含把失败动作改成成功动作所需的方向。有限步数下，重要的不是让 $c$ 有大方差，而是使 $\delta B$ 与关键状态的动作对比梯度对齐。

可以只用官方训练域已审核的共同前缀构造 $g_i=\nabla_B[\log\pi(a_i^+\mid q_i)-\log\pi(a_i^-\mid q_i)]$，在冻结底座与共享 $A$ 下对这些 $g_i$ 求低秩梯度子空间 $V$，让新超网络生成 $\delta B=Vc_\phi(\tau,q)$。若 $V$ 包含任务相关梯度，局部 margin 改善为 $g_i^\top Vc$；相反，若旧 $U$ 与 $g_i$ 近乎正交，哪怕旧子空间代码和矩阵范数显著变化也难改动作。这个预测能通过训练域的 $\|V^\top g_i\|/\|g_i\|$、$\|U^\top H_B^\top g_i\|/\|g_i\|$ 和符号一致率直接检验。计算 $V$ 时必须按有效矩阵或固定规范处理 LoRA 的 $A,B$ 规范自由度：$(B S)(S^{-1}A)$ 表示同一 $\Delta W$，不能把原始因子范数误当唯一经验强度。

训练目标先用 42 个**弱**共同前缀偏好做可行性检查；如果后续同策略配对执行发现偏好方向不一致，就替换为经环境验证的 advantage。生成器仍应从轨迹中的观察、动作、反馈、终局奖励编码，不输入人工任务类别。训练集只决定梯度基与超网络；测试时超网络冻结，当前题仅拿来自此前交互的轨迹生成/更新 LoRA，当前题奖励不能回写本题动作。每次更新可用 $c_{t+1}=\operatorname{Proj}_{\|c\|\le\rho}[\alpha c_t+(1-\alpha)c_\phi(\tau_t)]$，并额外检查动作分布 KL。这个公式是候选算法，尚未训练或验证；它的价值要由同预算在线题序、只保留最新经验的消融、同源原始文本和 ASCENT 式测试时反传对照决定。
