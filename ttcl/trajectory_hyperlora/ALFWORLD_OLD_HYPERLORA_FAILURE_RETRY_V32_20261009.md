# 旧版 68/134 轨迹 LoRA＋动作限制：失败轨迹参数修正

## 保留的旧版与新增步骤

旧版旧超网络、冻结 Qwen 演员、每题已审核训练域成功专家来源、动态任务反馈 LoRA、合法命令约束和同观察同动作两次重复抑制均保留。官方 `valid_unseen` 的 134 道已曝光目标题中，旧版**第一次尝试 68/134**，同轮无 LoRA＋动作限制 41/134。此次复用先前完整审计的 134 条旧版首次轨迹，不重选专家来源，也不把旧版模型换成后来未提升的训练检查点。

仅在旧版首次失败的 66 道题上增加**一次**同题重试。旧演员与动作限制相同，三个重试臂预算都是最多 50 步、每步 64 token：原 LoRA 原样重试；按失败轨迹生成的 `B_failed` 相对专家来源 `B_expert` 作远离修正；以及与真实修正的实际有效 LoRA 矩阵范数相同、但方向由固定种子随机生成的参数扰动。远离修正仍叠加在旧超网络逐步生成的 LoRA 上，而不是替换旧超网络。有效矩阵改动上限为初始专家 LoRA 的 25%。首次成功时三个重试臂均停止。

方向只由先前已用过的训练域 24 题开发结果选择：旧版首次／原样重试／朝失败方向重试均 **11/24**，远离失败方向 **13/24**；同范数随机方向 **11/24**。开发集两个新救回题不足以证明稳定收益，因此本轮 134 题仍为对已曝光题集的**描述性复测**，不称为独立最终测试。新轨迹目标重新绑定游戏、原始专家来源、已审计首次轨迹、旧检查点、代码与开发选择哈希；原始内容在 Git 忽略目录中。

## 官方结果与审计

134 题均已完成，零运行失败；完整独立原环境重放审计通过。旧版首次成功保持 **68/134**，因此只有 66 道首次失败题进入第二次尝试：

| 旧版首次成功即停止；失败后最多再试一次 | 最多两次内官方成功 |
|---|---:|
| 旧版首次，不重试 | 68/134 |
| 旧 LoRA 原样重试 | 68/134 |
| 失败轨迹方向的限幅参数修正 | **83/134** |
| 同有效矩阵范数的固定种子随机修正 | 74/134 |

原样重试未救回任何题；真实失败轨迹修正救回 15/66，单个匹配随机方向救回 6/66。两臂有 3 道共同救回；真实方向独有 12 道，随机方向独有 3 道。15 道救回分布于六种任务家族，但这批 134 题早已曝光，而且随机对照仅一个种子。结果只支持这次描述性复测，不能据此宣称稳定的失败内容泛化优势。首次 68/134 与两次内 83/134 预算不同，不能写成单次成功率提升。

原运行在前 42 题后退出；已完成行保持原样，并用 `resume_alfworld_failure_retry_v32_134.py` 续至第 107 题。后段由 `shard_alfworld_failure_retry_v32_134.py` 在不同 GPU 上独立运行 105–119 与 120–133；105、106 两道重叠题与顺序续跑结果逐字段一致。`merge_alfworld_failure_retry_v32_134.py` 校验目标、旧首次轨迹、代码与检查点哈希后合并，合并清单记录原前缀、分片及最终报告哈希。独立审计确认 66 条原样重试均逐字段等于旧首次失败记录，并对另 **132 条**修正／随机回合在原环境重放通过。完整报告 SHA-256 为 `186246c7cee41e70fbba3489292d1eb04d19b4a675be527a58f87f5d23536a06`。

**首次 68/134 与本轮最多两次尝试的成功数须分开解释**；不能把更多环境机会带来的成绩写成相同预算下的首次成功率提升。原样重试验证确定性旧演员在相同来源和状态下的第二次尝试；同范数随机方向检查任意参数扰动是否也能取得类似回报。即使真实方向优于一次随机种子，也仍需独立题集和多个随机扰动重复来支持稳定的失败内容效用。

实现：`evaluate_alfworld_failure_retry_v32_134.py`，独立环境重放：`audit_alfworld_failure_retry_v32_134.py`。本轮不训练旧超网络或 Qwen；“学习失败”特指从本题失败观察—动作—反馈轨迹生成并限幅应用参数修正，而不是把终局失败简单标成所有动作错误。
